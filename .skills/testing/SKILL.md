# SKILL: Testing

## Objetivo
Estruturar, escrever e executar suítes de testes unitários e de integração confiáveis.

## Diretrizes
- Escrever testes para lógica de negócio crítica, utilitários e serviços.
- Testar cenários felizes (happy path) e cenários de erro/exceção (error handling).
- Manter testes determinísticos e rápidos.
- Executar a suíte de testes com `npm test` antes de qualquer finalização de tarefa.
