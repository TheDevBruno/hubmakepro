# SKILL: Coding Standards

## Objetivo
Padronizar a escrita de código, tipagem, nomenclatura e documentação.

## Diretrizes
- **Linguagem:** TypeScript estrito (`strict: true`). Sem uso de `any`.
- **Idioma Funcional:** `pt-BR` para mensagens ao usuário, logs amigáveis, documentação funcional e feedback. Nomenclatura técnica em inglês (Services, Repositories, Hooks, Interfaces).
- **Tratamento de Erros:** Erros tratados explicitamente com mensagens informativas.
- **Pureza & Reutilização:** Componentes desacoplados e funções puras sempre que possível.
