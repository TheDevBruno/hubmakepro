# SKILL: GitHub Operations

## Objetivo
Padronizar a criação e gestão de Pull Requests, Issues e automações no GitHub.

## Diretrizes para Pull Requests
- Toda PR deve conter:
  1. Descrição clara do objetivo da Sprint/Task.
  2. Lista de mudanças e arquivos principais.
  3. Relatório de testes executados e evidências (prints para UI).
  4. Migrations aplicadas (se houver).
  5. Riscos mapeados e mitigados.
- Todo PR deve passar no workflow de CI (lint, typecheck, tests, build) antes do merge.
