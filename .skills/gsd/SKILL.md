# SKILL: GSD (Get Shit Done)

## Objetivo
Executar as metas de desenvolvimento com máximo foco, objetividade, velocidade e precisão técnica, eliminando desperdícios.

## Diretrizes Práticas
1. **Zero Overengineering:** Não crie abstrações ou fábricas complexas para casos de uso simples.
2. **Sem Funcionalidades Especulativas:** Desenvolva apenas o que está no Acceptance Criteria da Sprint.
3. **Sem Refatoração Silenciosa:** Não mexa em código fora do escopo sem Change Request aprovado.
4. **Resolução Imediata:** Foque na entrega do incremento de software funcionando, testado e validado.
