# SKILL: Authentication

## Objetivo
Implementar e validar fluxos de autenticação robustos e seguros com Supabase Auth.

## Diretrizes
- Responde à pergunta: **"Quem é o usuário?"**
- Gerenciamento seguro de cookies e tokens JWT via `@supabase/ssr`.
- Suporte a login por Email/Senha, Magic Link e OAuth seguro.
- Proteção de rotas via Middleware no Next.js com redirecionamento de usuários não autenticados.
