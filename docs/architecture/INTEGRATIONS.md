# INTEGRATIONS

## Catálogo de Integrações Externas

1. **Supabase (Core BaaS):**
   - Autenticação e Gestão de Sessões
   - Banco de Dados PostgreSQL & Extensions (uuid-ossp, pgcrypto)
   - Supabase Storage para arquivos e documentos
   - Realtime channels

2. **Vercel (Hosting & Delivery):**
   - Git Integration (Deploy automático a cada push em `feature/*` e `develop`)
   - Vercel Edge Middleware para verificação ultrarrápida de sessão
   - Vercel Analytics e Speed Insights

3. **Gateways de Pagamento (Fase 3):**
   - Stripe (Assinaturas, checkout e webhooks com validação de assinatura)

4. **Comunicação Transacional (Fase 2):**
   - Resend / Supabase Auth Emails (Templates em pt-BR)
